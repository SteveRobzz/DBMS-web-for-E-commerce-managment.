# E-Commerce Management System (ShopEase)
**Java + JDBC + Oracle Database web application** (DBMS Lab, PAT 4)

A web application where **customers** log in, pick products, and get a computed bill with a decision on whether the order can be placed. **Admins** log in to manage products, stock, orders, coupons and customers, and to view sales reports. All data is stored in Oracle and accessed through **JDBC** with the same 6 steps taught in Lab Ex 11.

---

## 1. What the application does

### Inputs → Processing → Output (customer side)

| Inputs from the user | Processing done by the application | Output shown |
|---|---|---|
| Quantity of each product | Checks stock in the `PRODUCTS` table and the max of 10 units per product | Error if stock is not enough |
| (logged-in customer) | Reads the customer's lifetime spend from `ORDERS` and sets a loyalty tier: ≥ ₹50,000 **PLATINUM 10%**, ≥ ₹20,000 **GOLD 7%**, ≥ ₹5,000 **SILVER 3%** | Loyalty discount |
| Coupon code | Checks the coupon exists, is active and not expired, and that the minimum order value is met. Discount = min(% of subtotal, max discount) | Coupon discount, or the reason it was ignored |
| (product category) | GST per category (Electronics 18%, Fashion 12%, Groceries 5%, Books 0%, Home 18%), charged on the discounted value | GST per item and in total |
| Delivery city | Free delivery if the order value after discount is ≥ ₹999; otherwise ₹40 for metro cities and ₹80 for other cities | Delivery charge |
| Payment mode | COD adds ₹30, and COD is **not allowed** above ₹20,000 | COD charge, or an error |
| **Place order** | **One transaction**: reduce stock → INSERT order → INSERT items (batch) → COMMIT, or ROLLBACK on any failure | Order number, saved order |

The final screen shows **"Order can be placed — amount payable ₹X"** or **"Order cannot be placed"** with the reasons. This works the same way as the loan-eligibility example in the question.

### Features
- **Login page** (SHA-256 hashed passwords, session cookie) and **customer registration**
- **Customer:** search and filter products, see membership tier and valid coupons, calculate the bill, place orders, view order history, cancel an order (stock is restored)
- **Admin:**
  - Dashboard with KPIs, low-stock alerts and recent orders
  - Add, update and delete products (a product that already appears in orders is hidden instead of deleted)
  - Order status workflow: PLACED → SHIPPED → DELIVERED, or CANCELLED
  - Customer list with each customer's spend and tier
  - Coupon management
  - Reports that use JOIN, GROUP BY, HAVING, sub-queries and a VIEW

## 3. Installation and setup (step by step)

### Step 1: Install Java (JDK 17 or later)
1. Download **Eclipse Temurin JDK 21** (LTS) from https://adoptium.net and install it. On Windows, tick **"Set JAVA_HOME"** and **"Add to PATH"** in the installer.
2. Open a new Command Prompt or terminal and check the installation:
   ```
   java -version
   javac -version
   ```
   Both commands should print version 17 or higher.

   If `javac` is not recognised on Windows: go to *System Properties → Environment Variables*, add `JAVA_HOME = C:\Program Files\Eclipse Adoptium\jdk-21...`, and add `%JAVA_HOME%\bin` to `Path`.

### Step 2: Install Oracle Database XE
**Windows:**
1. Download **Oracle Database 21c Express Edition for Windows x64** from https://www.oracle.com/database/technologies/xe-downloads.html.
2. Unzip it and run `setup.exe` as Administrator. Accept the defaults and set a password. This password is used for SYS, SYSTEM and PDBADMIN.
3. When setup finishes, note the connection details:
   - Port `1521`
   - Container database SID `XE`
   - Pluggable database service `XEPDB1`

**Linux / macOS (using Docker):**
```bash
# Intel / AMD machines
docker run -d --name oracle-xe -p 1521:1521 -e ORACLE_PASSWORD=oracle gvenzl/oracle-xe:21-slim
# Apple Silicon (M1/M2/M3): use Oracle 23ai Free instead; the service name is FREEPDB1
docker run -d --name oracle-free -p 1521:1521 -e ORACLE_PASSWORD=oracle gvenzl/oracle-free:23-slim
docker logs -f oracle-xe      # wait until it prints "DATABASE IS READY TO USE!"
```

Check that the database is running:
```
sqlplus system/<your_password>@localhost:1521/XEPDB1
```

### Step 3: Create the application user (schema)
Connect as SYSTEM to the pluggable database and run:
```sql
-- sqlplus system/<your_password>@localhost:1521/XEPDB1
CREATE USER ecom IDENTIFIED BY ecom123;
GRANT CREATE SESSION, CREATE TABLE, CREATE VIEW, CREATE SEQUENCE, CREATE TRIGGER TO ecom;
ALTER USER ecom QUOTA UNLIMITED ON USERS;
EXIT;
```
> **Oracle 11g XE:** there is no XEPDB1. Connect with `sqlplus system/<password>` and run the same commands.

### Step 4: Create the tables and insert the data (DDL + DML)
Open a terminal **inside the `ecommerce-management` folder** and run:
```
sqlplus ecom/ecom123@localhost:1521/XEPDB1
```
Then, at the `SQL>` prompt:
```sql
@sql/01_create_tables.sql
@sql/02_insert_data.sql
@sql/03_dml_queries.sql
```
- `@sql/03_dml_queries.sql` is optional. It shows SELECT, UPDATE, DELETE and SAVEPOINT/ROLLBACK, and ends with ROLLBACK so the data does not change.
- **On Oracle 10g / 11g**, run `@sql/01_create_tables_oracle11g.sql` instead of `01_create_tables.sql`.
- **To start again from scratch:** run `@sql/00_drop_tables.sql` first.
- **SQL Developer users:** open each file and press **F5** (Run Script).

Check that the data loaded:
```sql
SELECT USERNAME, USER_ROLE FROM APP_USERS;
SELECT COUNT(*) FROM PRODUCTS;      -- 13
```

### Step 5: Install the Oracle JDBC driver
The application needs **one jar file** in the `lib/` folder. Use either option:

**Option A: copy the driver that came with Oracle (no download needed)**

| Oracle version | Driver location |
|---|---|
| 21c XE (Windows) | `C:\app\<your-user>\product\21c\dbhomeXE\jdbc\lib\ojdbc11.jar` (or `ojdbc8.jar`) |
| 11g XE (Windows) | `C:\oraclexe\app\oracle\product\11.2.0\server\jdbc\lib\ojdbc6.jar` |

Copy that jar into `ecommerce-management\lib\`.

**Option B: download it from Maven Central**
```
# Windows (PowerShell or CMD on Windows 10/11)
curl -L -o lib\ojdbc11.jar https://repo1.maven.org/maven2/com/oracle/database/jdbc/ojdbc11/23.5.0.24.07/ojdbc11-23.5.0.24.07.jar

# Linux / macOS
curl -L -o lib/ojdbc11.jar https://repo1.maven.org/maven2/com/oracle/database/jdbc/ojdbc11/23.5.0.24.07/ojdbc11-23.5.0.24.07.jar
```
You can also download it manually from https://www.oracle.com/database/technologies/appdev/jdbc-downloads.html.

**How the driver is configured:**
- The run command puts every jar in `lib/` on the classpath: `-cp "out;lib\*"` on Windows, `-cp "out:lib/*"` on Linux/macOS. If you use an IDE, add the jar via *Project → Build Path → Add External JARs*.
- In the code, `Class.forName("oracle.jdbc.OracleDriver")` (in `DBConnection.java`) registers the driver.

### Step 6: Configure the connection (`db.properties`)
```properties
db.driver=oracle.jdbc.OracleDriver
db.url=jdbc:oracle:thin:@localhost:1521/XEPDB1     # 18c/21c (service name)
# db.url=jdbc:oracle:thin:@localhost:1521:XE       # 11g, or the SID style used in the lab
# db.url=jdbc:oracle:thin:@localhost:1521/FREEPDB1 # Oracle 23ai Free
db.user=ecom
db.password=ecom123
server.port=8080
```

### Step 7: Compile and run
**Windows:** double-click `run.bat`, or run:
```bat
mkdir out
javac -d out src\*.java
java -cp "out;lib\*" EcomApp
```
**Linux / macOS:**
```bash
chmod +x run.sh && ./run.sh
# or manually:
javac -d out src/*.java
java -cp "out:lib/*" EcomApp
```
When the application starts, the console shows:
```
[JDBC] Driver loaded : oracle.jdbc.OracleDriver
[JDBC] Connected to  : Oracle Oracle Database 21c Express Edition ...
 E-Commerce Management System is running
 Open  http://localhost:8080  in your browser
```

### Step 8: Open the application
Open **http://localhost:8080** in a browser.

| Role | Username | Password |
|---|---|---|
| Admin | `admin` | `admin123` |
| Customer (GOLD tier) | `arjun` | `arjun123` |
| Customer (REGULAR tier) | `priya` | `priya123` |

New customers can sign up from the **Create an account** link.

## 5. Where the JDBC steps from the lab are used

| JDBC step (Lab Ex 11) | Code |
|---|---|
| 1. Import package / load driver | `import java.sql.*;` and `Class.forName("oracle.jdbc.OracleDriver")` in `DBConnection.init()` |
| 2. Establish connection | `DriverManager.getConnection(url, user, password)` in `DBConnection.getConnection()` |
| 3. Create statement | `con.createStatement()` for fixed queries (dashboard, reports) and `con.prepareStatement(sql)` for anything with user input (login, register, checkout, CRUD) |
| 4. Execute SQL | `executeQuery()` for SELECT, `executeUpdate()` for INSERT/UPDATE/DELETE, `executeBatch()` for order items |
| 5. Process ResultSet | `while (rs.next()) { rs.getInt(...), rs.getString(...), rs.getDouble(...) }` |
| 6. Close connection | try-with-resources closes ResultSet, Statement and Connection automatically |
| Transactions | `con.setAutoCommit(false)`, then `con.commit()` / `con.rollback()` in `placeOrder()` and `cancelOrder()` |
| Generated keys | `prepareStatement(sql, new String[]{"ORDER_ID"})` and `getGeneratedKeys()` |

`PreparedStatement` with `?` placeholders is used for every query that contains user input. This protects the login form and the other forms from SQL injection.

## 7. About ODBC
This application connects with **JDBC** (Oracle thin driver, Type-4), so **no ODBC DSN is needed**. The JDBC driver talks to Oracle directly over TCP port 1521.

If your examiner asks for ODBC connectivity to the same database, for example from Excel or Python with `pyodbc`:
1. Install the **Oracle Instant Client Basic** and **ODBC** packages, unzip them, and run `odbc_install.exe` as Administrator.
2. Open **ODBC Data Source Administrator (64-bit)** (`odbcad32`) → *User DSN* → *Add* → select **Oracle in instantclient_xx**.
3. Fill in the fields:
   - Data Source Name: `ECOM_DSN`
   - TNS Service Name: `localhost:1521/XEPDB1`
   - User ID: `ecom`
4. Click **Test Connection** and enter the password `ecom123`.

This matches the ODBC chain in the lab slides: Application → ODBC API → Driver Manager → Oracle ODBC Driver → Oracle Database.

## 8. Troubleshooting

| Error | Fix |
|---|---|
| `ClassNotFoundException: oracle.jdbc.OracleDriver` | The jar is missing from `lib/`, or the classpath is wrong. Use `;` as the separator on Windows and `:` on Linux/macOS. |
| `ORA-01017: invalid username/password` | Check `db.user` / `db.password`, and that the user was created in **XEPDB1** (not in the root container). |
| `ORA-12514` / `ORA-12505` (listener does not know service/SID) | Use `/XEPDB1` (service name) for 18c/21c, or `:XE` (SID) for 11g. Check that the **OracleServiceXE** and **OracleOraDB21Home1TNSListener** Windows services are running. |
| `ORA-01950: no privileges on tablespace USERS` | Run `ALTER USER ecom QUOTA UNLIMITED ON USERS;` as SYSTEM. |
| `ORA-01031: insufficient privileges` when creating the view | Run `GRANT CREATE VIEW TO ecom;` as SYSTEM. |
| `ORA-02000: missing ALWAYS keyword` / identity error | You are on 11g. Use `01_create_tables_oracle11g.sql`. |
| `Address already in use: bind` | Port 8080 is busy. Change `server.port` in `db.properties`. |
| `javac` is not recognised | Install the JDK (not just a JRE) and add `%JAVA_HOME%\bin` to PATH. |
